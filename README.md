# Greeter CLI

A tiny command-line tool that greets people in color.

## Requirements

- Python 3.8+

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/broken-readme-test.git
cd broken-readme-test
```

Install the dependencies:

```bash
pip install -r requirement.txt
```

Or install it as a package:

```bash
python setup.py install
```

## Usage

Greet someone:

```bash
python main.py --name World
```

Greet someone several times:

```bash
python app.py --user World --times 3
```

Check the version:

```bash
python app.py --version
```

Run the basic example:

```bash
python app.py --name World
```

## Frontend

```bash
cd frontend
npm install
npm start
```

## Running tests

```bash
python -m pytest tests/
```
